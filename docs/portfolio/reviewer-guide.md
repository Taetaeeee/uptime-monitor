# 검토자 안내 (reviewer-guide)

## 기준 시점 (먼저 읽어 주세요)

- 이 문서와 README의 화면 설명은 **2026-11-13 구현 완료, 배포 확인 전, 신규 원격 CI 확인 전** 기준입니다. 라이브 URL에 새 화면(소개 띠, 실제/시연 요약 분리, 출처·상태 필터)이 적용됐다는 확인은 아직 없습니다.
- `docs/screenshots/` 이미지는 **이전 화면**이고 훈련 기록은 2026-11-12 시점입니다. 새 화면은 다시 촬영하지 않았습니다.
- 테스트 수: 로컬 JS 237개(상태 요약 25개 포함)는 로컬 통과이고 원격 CI는 확인하지 않았습니다. [이력서 문장](resume-lines.md)의 "JS 212개·Python 22개"는 2026-11-12 시점의 수치라 최신 코드의 수와 다릅니다(문서는 아직 갱신하지 않음). Python 22개는 화면 구현 1차에서 통과했고, 이후 화면 수정 때는 Python 코드가 바뀌지 않아 재실행하지 않았습니다.
- GitHub `main` 링크는 이미 푸시된 자료(훈련·평가)의 근거로만 쓰며, 이번 변경을 증명하지 않습니다(확인 전).

## 혼동하기 쉬운 것

- **"실제 점검" 배지 ≠ 지금 점검 중.** 출처가 실제 점검이라는 뜻입니다. 장애 훈련 대상은 "점검 대기"이며 과거 기록만 남습니다.
- **장애 #41은 실제 서비스 장애가 아닙니다.** 에이전트 실제 모드로 내 PC의 테스트 포트를 일부러 끈 훈련이고, 복구됨·사후 보고서 있음 상태입니다. 훈련 대상 카드(점검 대기)와 장애 당시 이력은 따로 읽습니다.
- **30분 규칙은 화면 요약 기준입니다.** 마지막 점검이 30분을 넘은 실제 대상은 상태 띠·요약 카드에서 "정상"으로 세지 않지만, 서버가 장애로 판정한 것이 아닙니다. 서버 판정은 2회 연속 실패이고, 에이전트 무응답(`agent_silent`)은 대상별로 켜야 하며 아직 켠 대상이 없습니다.
- **탐지율 44.7%는 서버 지표 공개 데이터의 값**이며 이 서비스의 HTTP 점검 성능이 아닙니다.
- **재생(`replay`)은 다른 조직의 과거 기록**이지 이 회사의 실시간 데이터가 아닙니다. 라이선스는 README 표에서 확인할 수 있고 Backblaze는 MIT가 아닙니다.

## 검증하지 않은 것

- 새 화면은 배포 전에 고정 응답 fixture와 Chrome CDP로 확인했습니다: 375px 모바일, 어두운/밝은 테마, 팝업 키보드 조작, 보고서·장애 상세 print 미디어. **실제 Worker와의 통합, 실제 PDF 페이지 나눔, 라이브 수치 대조는 하지 않았습니다.**
- 점검 대상 수나 서비스 수는 이 문서에 적지 않았습니다. 화면(`/api/status`)에서 확인해 주세요.
- 에이전트 무응답 감지를 켜서 하는 실제 환경 검증, 도메인 만료의 실제 조회(판정 로직만 있음), 점검 정밀도 5분 미만의 장애 감지는 없습니다.
