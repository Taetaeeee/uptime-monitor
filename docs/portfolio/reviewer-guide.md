# 검토자 안내 (reviewer-guide)

## 기준 시점 (먼저 읽어 주세요)

- 기준: **2026-11-19**. 이날 배포 DB에서 가짜 데이터(공개 데이터셋 재생·시뮬레이터·장애 훈련 기록)를 지우고, 코드·화면·문서를 정리했습니다. 이 정리의 배포·라이브 확인 결과는 README 맨 위 "문서 기준"을 보세요.
- `docs/screenshots/`의 이미지는 모두 **정리 전 화면**입니다(상태 페이지 2026-11-13, 장애 #41 2026-11-12). 지금은 지운 재생·시뮬레이터 카드가 보입니다.
- 테스트 수: JS 445개·Python 22개(2026-11-20 로컬 확인, 14단계 서비스 묶음·대시보드·서비스 상세·서비스 추가 포함). [이력서 문장](resume-lines.md)의 수치도 이 기준으로 맞췄습니다.
- GitHub `main` 링크는 현재 푸시된 코드를 가리킵니다.

## 혼동하기 쉬운 것

- **"실제 점검" 배지 ≠ 지금 점검 중.** 출처가 실제 점검이라는 뜻입니다. 점검을 꺼 둔 실제 대상은 "점검 대기"로 보입니다.
- **장애 #41은 실제 서비스 장애가 아닙니다.** 에이전트 실제 모드로 내 PC의 테스트 포트를 일부러 끈 훈련입니다. 2026-11-19에 DB와 화면에서 지웠고 PDF·스크린샷으로만 남아 있습니다.
- **화면 요약 규칙 (2026-11-19 대시보드 새 디자인 이후):** 예전 상태 페이지의 '30분 넘게 점검 기록 없음' 규칙은 새 대시보드에 없습니다. 요약 칸은 서버가 판정한 서비스 상태(정상·부분 장애·장애 등)를 세고, 3분 넘게 새 데이터를 못 받으면 '연결 지연'만 표시합니다. 서버 판정은 2회 연속 실패이고, 에이전트 무응답(`agent_silent`)은 대상별로 켜야 하며 아직 켠 대상이 없습니다.
- **탐지율 44.7%는 서버 지표 공개 데이터의 값**이며 이 서비스의 HTTP 점검 성능이 아닙니다.
- **성능 측정에 쓴 공개 데이터셋(SMD·NAB)은 오프라인 계산에만 썼고** DB·화면에는 없습니다. 라이선스는 README의 성능 측정 절에 있습니다.

## 검증하지 않은 것

- **라이브 확인(2026-11-19, 대시보드 새 디자인 d87e560):** `/`·`/services`·`/incidents`·`/evidence`, `/api/services`·`/api/status` 200, 콘솔 오류 없음, 1440px에서 배치 측정값이 미리보기와 같음. 375px 모바일은 배포 전 로컬 미리보기에서만 확인했습니다.
- **라이브 확인(2026-11-13, 가짜 데이터 정리 전):** 주요 정적 파일·`/api/status`·`/api/incidents/41`(지금은 삭제되어 없음)·월간 보고서 API 응답과 `/report.html`·`/incident.html?id=41` 리다이렉트 정상, 상태 띠·요약 카드의 분모가 `/api/status`의 실제 활성 대상 수와 일치, 데스크톱 어두운/밝은 화면 확인. 배포 전에는 고정 응답 fixture와 Chrome CDP로 375px 모바일, 양 테마, 팝업 키보드, 보고서·장애 상세 print 미디어를 확인했습니다. **라이브에서의 375px·필터·팝업 조작, 실제 PDF 페이지 나눔은 확인하지 못했습니다.**
- 점검 대상 수나 서비스 수는 이 문서에 적지 않았습니다. 화면(`/api/status`)에서 확인해 주세요.
- 에이전트 무응답 감지를 켜서 하는 실제 환경 검증, 도메인 만료의 실제 조회(판정 로직만 있음), 점검 정밀도 5분 미만의 장애 감지는 없습니다.
