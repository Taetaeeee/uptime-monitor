서비스 현황

카드를 누르면 자세한 정보가 팝업으로 열립니다. 출처 배지로 실제 점검과 시연 데이터를 구분하세요.

실제 점검
내가 운영하는 사이트·서비스를 Worker(Cron)가 직접 점검하거나, 내 PC의 Python 에이전트가 실제 모드로 측정해 보낸 기록입니다. 점검 대기 대상은 지금 점검하지 않습니다.
실제 데이터 재생
다른 조직의 과거 운영 기록을 이 프로젝트가 5분마다 한 칸씩 재생한 것입니다. 이 회사의 실시간 데이터가 아니며, 장애·복구 시각은 원본 기록의 과거 시각이 아니라 이 프로젝트가 재생을 실행한 시각(5분 회차)입니다.
시뮬레이터
시나리오 파일의 가짜 측정값입니다. PC에서 에이전트를 실행해 수동으로 보낼 때만 갱신됩니다.
데모 데이터
시드 스크립트로 넣은 가짜 기록입니다(현재 배포에서는 정리되어 보이지 않을 수 있음).

장애 이력

최근 장애를 시작 시각 순으로 정리했습니다. 누르면 사후 보고서를 볼 수 있어요. 목록은 당시 기록이며 지금의 점검 상태와는 별개입니다.

읽는 길: 장애를 누르면 사후 보고서(요약·영향·원인·조치·재발 방지)를, 월간 보고서에서 가동률·SLA를 볼 수 있습니다.

판정·집계 로직을 순수 함수로 분리해 테스트하고, 푸시마다 CI에서 JS·Python 테스트를 다시 실행합니다.

테스트 코드 · CI 실행 결과

알려진 한계 (2026-11-13 기준)

  • 도메인 만료는 판정 로직만 있고 실제 조회는 하지 않습니다.
  • 에이전트 무응답 감지는 운영에서 켠 대상이 없습니다.
  • 실제 점검은 2026-11-11부터라 기간이 짧습니다.
  • 점검 정밀도는 5분입니다(그보다 짧은 장애는 놓칠 수 있음).

서비스 상세

웹 서비스(HTTP·DNS)는 Worker가, 사내 시스템(ping·포트·디스크·인증서·서비스)은 Python 에이전트가 점검하고, 2회 연속 실패를 장애로 판정해 기록합니다.

실제 점검 기록의 출처가 실제 점검이라는 뜻이며 지금 점검 중이라는 뜻은 아닙니다. 상태와 점검 시각을 함께 보세요.

데모 데이터 시뮬레이터 표시가 붙은 항목은 시연용 가짜 데이터(시드 스크립트·에이전트 시뮬레이터)이며 실제 점검 결과가 아닙니다. 서비스·회사 이름은 모두 가상입니다.

실제 데이터 재생 공개된 실제 운영 데이터셋(다른 조직의 과거 기록)을 5분마다 한 칸씩 재생한 것입니다. 가짜 값은 아니지만 이 회사의 실시간 데이터도 아닙니다. 서비스를 누르면 데이터셋 이름·링크·라이선스·가공 방법을 볼 수 있습니다.
