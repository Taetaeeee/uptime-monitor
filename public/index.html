서비스 상세

가상 회사의 웹 서비스(HTTP·DNS)는 Worker가, 사내 시스템(ping·포트·디스크·인증서·서비스)은 Python 에이전트가 5분마다 점검하고, 2회 연속 실패를 장애로 판정해 기록합니다.

데모 데이터 시뮬레이터 표시가 붙은 항목은 시연용 가짜 데이터(시드 스크립트·에이전트 시뮬레이터)이며 실제 점검 결과가 아닙니다. 서비스·회사 이름은 모두 가상입니다.
