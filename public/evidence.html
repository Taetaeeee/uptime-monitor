알려진 한계 (2026-11-19 기준)

  • 도메인 만료는 판정 로직만 있고 실제 조회는 하지 않습니다.
  • 에이전트 무응답 감지는 운영에서 켠 대상이 없습니다.
  • SSL 인증서 만료는 Worker에서 잴 수 없어 점검하지 않습니다(인증서가 깨지면 HTTP 점검이 실패로 잡음).
  • 실제 점검은 2026-11-11부터라 기간이 짧습니다.
  • 점검 정밀도는 5분입니다(그보다 짧은 장애는 놓칠 수 있음).

웹 서비스(HTTP·DNS)는 Worker가 5분마다 점검하고, 2회 연속 실패를 장애로 판정해 기록합니다.
