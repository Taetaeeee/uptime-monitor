조사 설정

관측 출처

가상 장애 상황의 관측을 순서대로 엽니다. 실제 서비스 장애나 RCAEval 실험이 아닙니다.

RCA 전용 토큰입니다. 브라우저에 저장하지 않습니다. OpenAI API 키를 여기에 입력하지 마세요.

실행은 서버 비용 한도 안에서 이 연결 동안 진행됩니다. 중단해도 이미 진행된 모델 호출의 과금이 멈춘다고 보장할 수 없습니다.

        합성 DNS·HTTP

        가상 시나리오에서 도구 선택과 추가 관측 흐름을 시연합니다. 실제 사건과 연결하지 않습니다.

        실제 점검

        등록된 내 서비스의 기록과 새 DNS·HTTP 측정만 사용합니다. 서버 내부 로그·CPU·사용자 데이터는 제공되지 않습니다.
